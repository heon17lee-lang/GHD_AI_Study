# AI 업무 메이트 찾기

AI 교육 첫 모임에서 사용하는 모바일 기반 AI 업무 스타일 진단 웹앱입니다.

각 STEP 사이에 해당 주제를 표현한 일러스트 전환 화면이 나타나며, 진단 문항의 보기는 테스트를 시작할 때마다 무작위로 섞입니다. 단, OX 문항은 O가 왼쪽, X가 오른쪽에 고정됩니다. 결과 화면에서는 유형별 전용 캐릭터가 들어간 인스타그램 스토리용 9:16 PNG 카드를 휴대폰 공유창으로 전송할 수 있고, 공유를 지원하지 않는 환경에서는 파일로 내려받을 수 있습니다.

## 실행

별도의 빌드 과정이나 서버가 필요하지 않습니다. `index.html`을 브라우저에서 열면 바로 실행됩니다.

브라우저 보안 정책으로 공유 기능을 온전히 확인하려면 간단한 로컬 서버를 사용할 수 있습니다.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000`에 접속합니다.

## 파일 구성

- `index.html`: 앱의 기본 문서와 메타데이터
- `styles.css`: 모바일 반응형 디자인
- `questions.js`: 25개 문항, 결과 유형 및 점수 기준
- `scoring.js`: 영역별 점수 계산과 결과 유형 판정
- `mbti.js`: MBTI 보너스 콘텐츠(결과 화면 전용, 점수 계산과 무관)
- `sheet-config.js`: 구글 스프레드시트 응답 기록용 웹 앱 URL 설정
- `app.js`: 화면 전환, 응답 처리 및 결과 표시
- `assets/steps/`: STEP별 맥락 일러스트 6종
- `assets/results/`: 결과 유형별 전용 캐릭터 이미지와 반복 영상 각 6종
- `.nojekyll`: GitHub Pages의 Jekyll 처리를 비활성화

## 데이터 처리

모든 점수 계산은 사용자의 브라우저에서 이루어집니다. `sheet-config.js`의 `SHEET_ENDPOINT`가 비어 있으면 응답은 저장되거나 외부로 전송되지 않고, 페이지를 닫거나 새로고침하면 초기화됩니다.

`SHEET_ENDPOINT`에 배포된 Google Apps Script 웹 앱 URL을 넣으면, 참가자가 결과 화면에 도달하는 시점에 닉네임·업무·MBTI·문항별 응답·점수·결과 유형이 담긴 한 줄이 연결된 구글 스프레드시트에 자동으로 기록됩니다. 이 기능을 켤 경우, 참가자에게 응답이 기록된다는 사실을 미리 안내하는 것을 권장합니다.

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소에 올립니다.
2. 저장소의 `Settings → Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. 배포할 브랜치와 루트 폴더를 선택하고 저장합니다.

상대 경로만 사용하므로 별도의 경로 수정 없이 프로젝트 페이지에서도 동작합니다.
